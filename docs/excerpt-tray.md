# 摘录托盘

`ExcerptTray` 是可复用、受控的摘录阅读组件：它不改写 Markdown，也不直接持久化 sidecar。调用方只需提供摘录列表和删除/定位回调。

它按一级标题提供类别筛选，并支持“最新采集 / 最早采集 / 原文位置”排序。每条摘录可复制原文、来源引用或可直接粘贴的 Markdown 块；来源引用使用显示文件名和完整标题路径。

键盘操作在聚焦摘录卡时可用：方向键切换卡片，Enter 返回原位置（调用方提供定位回调时），Delete 或 Backspace 删除，Ctrl/Cmd+C 复制原文，Ctrl/Cmd+R 复制来源引用，Ctrl/Cmd+M 复制 Markdown。剪贴板不可用时会显示非阻塞提示。

排序和筛选是视图派生状态，不会重排或更改 sidecar 中的摘录；`reorderExcerpts()` 作为纯函数提供给需要持久化手动排序的原生宿主。
