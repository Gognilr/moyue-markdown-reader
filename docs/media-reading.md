# 图片阅读能力

图片灯箱保持 Markdown 原文和图片地址不变，提供可重复使用的阅读操作：

- `+` / `-` 或工具栏按钮以 25% 步进缩放，范围为 25% 到 400%。
- `0` 或百分比按钮复位为 100%。
- `Esc` 或点击遮罩关闭预览。
- “复制图片地址”只尝试浏览器标准 Clipboard API；不可用时显示失败状态，不会伪造已复制。

“打开原文件”不是默认权限。宿主若已经取得本地文件访问授权，可向 `ImageLightbox` 传入 `onOpenSource(src)`；组件仅调用该回调，不读取路径、也不把远程 URL 当作本地文件打开。这使 Web 与 Tauri 容器能够各自采用明确且最小的权限策略。
