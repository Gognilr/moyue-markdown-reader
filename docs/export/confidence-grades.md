# 导出可信度等级

导出前会运行 `preflightExport(document, options)`。它只检查 `DocumentIR`、原始 Markdown 和调用方提供的本地资源清单；不访问网络、DOM 或文件系统。

## A/B/C 的含义

- **A — 结构性预检通过（非视觉验证）**：预检规则没有发现降级项。它仅证明已经运行了语义结构和规则检查。
- **B — 可导出但有记录的风险**：远程资源、超宽表、或不在 `DocumentIR` 契约内的 HTML 等风险会列出位置、证据和建议，导出结果也会保留这些降级原因。
- **C — 确定性阻塞**：空/不安全资源或调用方资源清单明确缺失的本地资源会阻止导出。

任何等级都**不**证明 Word 或 PDF 查看器中的像素级版式、字体替换、CJK 字体嵌入、Office 实际分页或无障碍合规。那些项目需要对应的真实渲染器/规范验证，不能由 A/B/C 代替。

## 展示与可追溯性

预检面板显示当前等级、已运行的规则证据及每项降级原因。成功触发 DOCX/PDF 下载后，工具栏保留同一份结果摘要；通知也包含等级。这样导出的结果不会被描述为已经完成视觉验证。

`ExportPreflightReport.evidence` 与 `downgradeReasons` 为纯数据，测试和未来原生导出后端可复用它们，而不依赖 UI 文案。
