# 隐私说明

最后更新：2026-07-19

Markdown 阅读器是一款本地优先桌面应用。

## 默认处理方式

- Markdown 正文、编辑内容、历史记录、收藏、阅读位置和未保存草稿在本机处理或保存。
- 应用不要求账户，不包含项目自建的遥测、广告或云同步服务。
- 应用不会默认把文档正文上传给项目维护者。

## 文件访问

- 文档访问来自系统文件选择器、拖入、文件关联、用户点击已记录的最近文件或其他明确触发的功能；应用仅为曾明确打开过的 Markdown 恢复本地授权。
- 本地图片只允许从当前已授权 Markdown 目录中的安全相对路径读取。
- 导出只写入用户在原生“另存为”对话框中选择的目标文件。
- 可选的资源管理器快速预览会在当前用户注册表中添加 `.md/.markdown` 右键命令；可以在应用内移除，卸载时也会清理。

## 网络访问

- Markdown 中的远程图片或外部链接可能让 WebView 或系统浏览器连接第三方服务器，从而暴露 IP 地址、User-Agent 等常规网络信息。
- Mermaid、KaTeX、DOCX、PDF 和 XLSX 处理在本机完成。
- 依赖安装、GitHub Actions、GitHub Releases 和系统更新检查不属于阅读器正文上传。

## 本地数据清理

卸载应用会移除应用程序和安装器管理的注册表项。WebView/应用设置中的历史、布局或草稿是否由安装器一并移除取决于 Windows/Tauri 的用户数据保留行为；处理敏感设备前，用户应在系统应用数据目录中检查并手动删除残留设置。

## 第三方内容

用户打开的 Markdown、远程资源和外部链接受其来源方隐私政策约束。请不要在公开 Issue 中上传包含个人信息、密钥、内部路径或未授权内容的真实文档。
