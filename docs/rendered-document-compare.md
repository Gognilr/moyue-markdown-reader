# 渲染态文档对比核心

`src/features/render-diff/documentCompare.ts` 提供纯函数 `compareMarkdownDocuments`。它将两份 Markdown 解析为阅读语义块，再比较标题、段落、列表项、表格行和代码块；不会按原始文本行直接做 diff。

## 支持的输入来源

调用方可把磁盘版本、上次保存版本、指定文件或 Git 版本的文本传入同一个函数。核心不读取文件、不会调用 Git，也不会保存任何数据，因此适用于浏览器与 Tauri 容器。

## 对齐与表格

完全相同的语义块通过 LCS 保持原文顺序。其余同类块用词元相似度与章节路径配对，形成新增、删除或修改。表格行在传入 `tableKeyColumn` 时按该列主键配对；没有主键时按单元格最佳匹配，并为每个单元格给出变化状态。

## 视图组件

`DocumentCompareView` 是可复用、受控的双栏组件，左右滚动位置会同步；点击差异时通过 `onSelectEntry` 把带有源行号和标题路径的语义块交回宿主。它尚未接入主阅读页，也不负责加载版本、跳转编辑器或导出带修订痕迹的 Word/PDF。
